# Quickstart — gregPlugin.SteamModfix

> gregPlugin.SteamModfix

Repo: [https://github.com/mleem97/gregPlugin.SteamModfix](https://github.com/mleem97/gregPlugin.SteamModfix) · Version: `0.1.0` · Lizenz: MIT.

## 1. Klonen

```bash
git clone git@github.com:mleem97/gregPlugin.SteamModfix.git
cd gregPlugin.SteamModfix
```

## 2. Bauen / Starten

Je nach Tech-Stack **einen** Weg wählen:

```bash
# .NET
dotnet build -c Release
dotnet run --project src/

# Node / pnpm
pnpm install
pnpm build
pnpm start

# Python
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m <modul>
```

## 3. Testen

```bash
dotnet test            # .NET
pnpm test              # Node
pytest                 # Python
```
